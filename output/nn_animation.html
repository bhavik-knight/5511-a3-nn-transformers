4. Mathematical Walkthrough (Epoch 1, Simulated Sample 1)

Using the exact logic from train_neural_network(). We trace the math for a single sample (Iris-setosa) with the random seed 42 initialized weights.

Step 1: Initialization

Step 1/6

First, we initialize weights randomly using normal distribution scaled by 0.01, and bias to 0.

# np.random.seed(42)
weights = np.random.randn(4, 1) * 0.01
bias = 0.0

# Generated Initial Values:
W₀ = [ 0.00497, -0.00138, 0.00648, 0.01523 ]ᵀ
b₀ = 0.0

# We pull our first training sample (Setosa):
X₁ = [ 5.1, 3.5, 1.4, 0.2 ]
y₁ = 0

Forward Pass (Part 1): We compute the linear weighted sum Z.

# Z = np.dot(X, weights) + bias

Z = (X₁[0] × W₀[0]) + (X₁[1] × W₀[1]) + (X₁[2] × W₀[2]) + (X₁[3] × W₀[3]) + b₀

Z = (5.1 × 0.00497) + (3.5 × -0.00138) + (1.4 × 0.00648) + (0.2 × 0.01523) + 0

Z = 0.02534 - 0.00483 + 0.00907 + 0.00304
Z = 0.03262

Forward Pass (Part 2): We pass Z through the Sigmoid Activation function to squeeze the output between 0 and 1.

# def sigmoid(z): return 1 / (1 + np.exp(-z))
# A = sigmoid(Z)

A = 1 / (1 + e^(-0.03262))
A = 1 / (1 + 0.9679)

A = 0.5081 (Prediction ~50.8%)

The network is effectively guessing randomly right now, leaning slightly towards class 1. But the true target y₁ is 0.

Backward Pass (Error): We compute the gradient of the loss with respect to Z. Due to the math of Binary Cross Entropy + Sigmoid, this simplifies beautifully.

# dZ = A - y

dZ = 0.5081 - 0
dZ = 0.5081

The error is positive, meaning the raw output Z was too high and needs to be pushed down.

Calculating Gradients: How much did each weight and bias contribute to this error? We use the chain rule (backpropagation).

# dW = (1 / n_samples) * np.dot(X.T, dZ)
# db = (1 / n_samples) * np.sum(dZ)
# *Showing single sample contribution before averaging*

dW = X₁ᵀ × dZ
dW₀ = 5.1 × 0.5081 = 2.591
dW₁ = 3.5 × 0.5081 = 1.778
dW₂ = 1.4 × 0.5081 = 0.711
dW₃ = 0.2 × 0.5081 = 0.101

db = dZ = 0.5081

Parameter Update: We turn the "dials" in the opposite direction of the gradient using Gradient Descent with learning_rate = 0.1.

# weights -= learning_rate * dW
# bias -= learning_rate * db
# *Assume dW_avg is averaged over the batch of 80*

W_new = W_old - (0.1 × dW_avg)
b_new = b_old - (0.1 × db_avg)

# Over 2000 epochs, this loop drives the weights to:
Final Weights = [ -0.6315, -2.3114, 3.5669, 1.6128 ]ᵀ
Final Bias = -0.4233

Notice how Sepal Width (W₁) became highly negative, and Petal Length (W₂) became highly positive to perfectly separate the two Iris classes!
